# FlyBrain Browserbase Gateway — Staging

Isolated Node.js MCP gateway for Browserbase-hosted Chromium. This service is separate from the existing Production bridge.

## Environment
- BROWSERBASE_API_KEY: Browserbase secret; set only in Render Environment.
- BROWSERBASE_PROJECT_ID: Browserbase project ID; set only in Render Environment.
- MCP_ACCESS_TOKEN: generated by Render Blueprint; clients send it as Bearer token.

## Tools
Eight MCP tools: open, navigate, snapshot, click, type, press, screenshot, close.

Every new session requires an explicit HTTPS hostname allowlist. Requests outside the allowlist are blocked at the Playwright routing layer. Click, type and press require allowSideEffects=true. Sessions are held in process memory; closing a session releases remote browser resources. Restarting the Render instance invalidates local session handles.

## Deploy
Render Blueprint: ../render-flybrain-browser-staging.yaml. Branch is restricted to the FlyBrain Staging branch. Free instance may sleep after inactivity; browser session usage is limited by the Browserbase plan.
